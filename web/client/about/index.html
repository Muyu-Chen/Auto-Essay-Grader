关于 Auto Essay Grader

什么是 Auto Essay Grader？

Auto Essay Grader 自动作文评分系统，是一个基于先进语言模型 API 的自动评分工具，旨在帮助用户快速、准确地批量评分作文。通过简单的操作，您可以上传包含作文的 Excel 文件，定义评分标准，工具会自动生成分数和反馈。

作者是谁？

此项目由 Muyu Chen 开发，目标是通过技术简化教育工作流程，提高作文批改效率。此前尝试过商业化分支，目前相关功能已经回流到开源仓库统一维护。

如何使用？

当前仓库同时提供桌面端和网页端。桌面端位于 client/，网页端位于 web/，后端服务位于 server/。

启动后端后，可以打开 网页登录页，也可以继续使用桌面端客户端。

核心功能

  • 批量作文评分：支持 Excel 文件导入，一次性评分多篇作文。
  • 自定义评分标准：根据任务需求设置评分维度，例如任务完成度、连贯性、词汇多样性和语法准确性。
  • 支持多种模型选择：根据性能和成本需求选择适合的语言模型。
  • 详细的评分反馈：自动生成作文分数并附带评语。
  • 用户友好界面：简单直观的操作流程。

如何使用开源项目？

使用 Auto Essay Grader 非常简单：

  1. 打开项目地址并点赞。
  2. 下载项目到本地并解压。
  3. 安装依赖并配置 API 密钥。
  4. 准备 Excel 文件，将作文内容放入一列。
  5. 运行后端和前端程序，启动工具。
  6. 定义评分标准并上传文件。
  7. 点击提交，等待系统生成评分和反馈。
